## 7 องค์ประกอบตามแบบประเมินด้านการออกแบบ

กรอบการออกแบบอยู่ใน `src/design.mjs` (7 องค์ประกอบ × 28 ข้อของแบบประเมินคุณภาพด้านการออกแบบ กระบวนการคิดสร้างสรรค์ 4 ขั้นตาม Guilford และจารุณี ซามาตย์ ฐานการช่วยเหลือ 4 ด้าน แผนผังความคิด และการโค้ช 3 บทบาท) ใช้ร่วมกันทั้งคู่มือบทที่ 9 การ์ด โปสเตอร์ และฉบับดิจิทัล

## ทอยประโยค (ช่องทรัพยากร)

ช่องป่าไม้ เตาอิฐ เหมืองหิน และร้านแก้วสี 12 ช่องมีคำกริยาพิมพ์ไว้ (➜ ปลูก ตัด ทาสี …) หยุดแล้วทอยลูกเต๋าใคร + ลูกเต๋าประเภทประโยค และจั่ว**การ์ดเวลา** 1 ใบ (4 กาล: ทำไปแล้ว · ทำเป็นประจำ · กำลังทำ + กำลัง · จะทำ + จะ) แล้วพูดประโยคให้ครบ ผ่านได้ทรัพยากร + บล็อกคำ 2 ใบ ใส่การ์ดขยายเพิ่ม (สถานที่ · อย่างไร) ได้ถูก ได้บล็อกเพิ่ม 1 — ดัดแปลงจาก Sentence Maker (ELI): กริยาบนช่อง + เต๋าสรรพนาม + เต๋ารูปประโยค + การ์ดคำบอกเวลา 4 tense กติกาเต็มอยู่ในคู่มือบทที่ 3

จัดหาเพิ่ม: ลูกเต๋าธรรมดา 1 · นาฬิกาทราย 5 นาที · ไวท์บอร์ดเล็ก + ปากกา 4 ชุด

## แก้ไขเนื้อหาและสร้างไฟล์ใหม่

เนื้อหาทั้งหมด (คำบนบล็อก ภารกิจ การ์ดภัย ตารางที่ 2 ตัวบ่งชี้ คำถามโค้ช) อยู่ใน `src/data.mjs` แก้แล้วสร้าง PDF ใหม่ด้วย

```bash
npm install        # ครั้งแรก (ใช้ Playwright + Chromium)
pip install pypdf  # ใช้ตัดกระดานเป็น A3 สองแผ่น
npm run build      # หรือ node src/build.mjs 03-  เพื่อสร้างเฉพาะไฟล์ที่ชื่อมี "03-"
```

ฟอนต์ Mitr และ Sarabun (SIL Open Font License) อยู่ใน `fonts/` และฝังใน PDF แล้ว
