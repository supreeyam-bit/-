# ดินแดนมหัศจรรย์แห่งคำ — ฉบับดิจิทัล

เกมหน้าเดียว `wordland.html` เปิดในเบราว์เซอร์ได้ทันที (แท็บเล็ตหรือคอมพิวเตอร์ 1 เครื่อง ผู้เล่น 2–4 คนผลัดกัน)

- กระดาน 36 ช่อง ทอยเต๋า เดิน และทำตามช่องแบบเดียวกับชุดพิมพ์
- ต่อประโยคด้วยการแตะบล็อกคำบนแท่นวาง ระบบตรวจโครงสร้างและประเภทประโยคให้ (บอกเล่า ปฏิเสธ คำถาม คำสั่ง ขอร้อง)
- ภารกิจซ่อมป้าย 36 ภารกิจตรวจคำตอบอัตโนมัติ เมื่อผิด **ครูฮูก** ถามคำถามตามบันไดการโค้ช โดยไม่บอกคำตอบ และเปิดการ์ดคำใบ้ 3 ขั้นได้
- ภารกิจสร้างสรรค์ 4 ด้าน × 3 ด่าน (ตารางที่ 2) จับเวลา 5 นาที ทุกคนเขียนพร้อมกัน เพื่อนตรวจ คัดลอกคำตอบเก็บเป็นหลักฐานได้
- ภารกิจร่วม 3 สิ่งมหัศจรรย์ ตลาดแลกคำ ภัยยุ่งเหยิง 16 แบบ การโจมตีเมืองและการซ่อม นิทานเมืองของฉัน และตารางนับแต้ม
- **แหล่งเรียนรู้** (แทนการสแกน AR): แตะไม้ อิฐ หิน หรือแก้วสี เพื่อเปิดบทเรียน 3 ส่วนย่อยพร้อมแบบฝึกสั้น ๆ
- บันทึกเกมไว้ในเครื่องอัตโนมัติ

## แก้ไขเนื้อหา

เนื้อหาร่วมกับชุดพิมพ์อยู่ที่ `../print-and-play/src/data.mjs` ส่วนบล็อกของภารกิจฉบับดิจิทัลอยู่ที่ `src/missions.mjs` ตัวเกมอยู่ที่ `src/template.html` แก้แล้วสร้างไฟล์ใหม่ด้วย

```bash
node digital/build.mjs
```

# ตำนานสร้างเมืองประโยค — เกมวางแผ่นภาพ (ฉบับดิจิทัล)

ไฟล์เดียว `sentence-city.html` เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง (คอมพิวเตอร์หรือแท็บเล็ต ผู้เล่น 2–4 คนผลัดกันเล่นบนเครื่องเดียว)

- กองแผ่นภาพ 48 แผ่น + แผ่นเริ่มต้น 1 แผ่น วาดด้วย SVG แบบโลกบล็อก เมือง 3 ธีม (หลังคาส้ม/เขียว/ชมพู) และหอคอย 4 สี
- ไฮไลต์ช่องที่วางได้ หมุนแผ่นทีละ 90° ขอบต้องตรงกันทุกด้าน ถ้าไม่มีช่องวาง เกมคืนแผ่นใต้กองแล้วจั่วใหม่
- **ด่านสร้างเมือง**: ตอบคำถามตามธีม (เลือกตอบ 3 ตัวเลือก หรือลาก/แตะคำมาเรียงเป็นประโยค) ผิดครั้งแรกได้คำใบ้และตอบใหม่ ผิดครั้งที่สองแสดงเฉลย วางแผ่นได้แต่วางตัวผู้เล่นไม่ได้
- **ด่านสร้างหอคอย**: ภารกิจคิดคล่อง/ยืดหยุ่น/ริเริ่ม/ละเอียดลออ จับเวลา แล้วให้เพื่อนหรือครูติ๊กเกณฑ์และกด “ตรวจแล้วผ่าน” (หอคอยสีส้มให้ผู้เล่นคนอื่นโหวตก่อน)
- นับคะแนนถนน เมือง โล่ หอคอย ชาวนา และพื้นที่ที่ยังไม่เสร็จตอนจบเกม · การ์ดตัวช่วยคนละ 2 ครั้ง · คลังความรู้ · เสียงเอฟเฟกต์ปิดได้
- บันทึกทุกคำตอบ (ชื่อ ธีม/สี หัวข้อ ตัวบ่งชี้ คำถาม คำตอบ ถูก/ผิด เวลา) ดาวน์โหลดเป็น CSV (เปิดใน Excel/Google Sheets ได้)
- ไม่เก็บข้อมูลลงเครื่องและไม่ส่งข้อมูลออกนอกเครื่อง (ต้องใช้อินเทอร์เน็ตเฉพาะการโหลดฟอนต์ ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน)

## แก้ไขคำถามและภารกิจ

เปิด `sentence-city.html` ด้วยโปรแกรมแก้ข้อความ แล้วแก้ตัวแปร `GAME_DATA` ที่ส่วนต้นไฟล์ (รูปแบบ JSON)

| ส่วน | ใช้ทำอะไร |
|---|---|
| `tileSet` | จำนวนแผ่นแต่ละประเภท ปรับให้ตรงกับตารางประเภทแผ่น (ตารางที่ 12) ได้ ดูภาพแต่ละประเภทในหน้า “วิธีเล่น” |
| `topics`, `indicators` | หัวข้อของแต่ละเมือง และรหัสตัวบ่งชี้ 1.1–4.3 ที่บันทึกลง CSV |
| `cityQuestions` | คลังคำถาม 3 เมือง เมืองละ 5 หัวข้อ หัวข้อละ 3 ข้อ |
| `towerMissions` | ภาพ ประโยคตั้งต้น คำสุ่ม และประโยคที่ต้องแก้ของหอคอย 4 สี รวมทั้งเวลา (วินาที) |
| `knowledge` | เนื้อหาในหน้าคลังความรู้ |
| `scoring` | ค่าคะแนน |
