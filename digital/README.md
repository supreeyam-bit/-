# ดินแดนมหัศจรรย์แห่งคำ — ฉบับดิจิทัล

เกมหน้าเดียว `wordland.html` เปิดในเบราว์เซอร์ได้ทันที (แท็บเล็ตหรือคอมพิวเตอร์ 1 เครื่อง ผู้เล่น 2–4 คนผลัดกัน)

- กระดาน 36 ช่อง ทอยเต๋า เดิน และทำตามช่องแบบเดียวกับชุดพิมพ์
- ต่อประโยคด้วยการแตะบล็อกคำบนแท่นวาง ระบบตรวจโครงสร้างและประเภทประโยคให้ (บอกเล่า ปฏิเสธ คำถาม คำสั่ง ขอร้อง)
- ภารกิจซ่อมป้าย 36 ภารกิจตรวจคำตอบอัตโนมัติ เมื่อผิด **ครูฮูก** ถามคำถามตามบันไดการโค้ช โดยไม่บอกคำตอบ และเปิดการ์ดคำใบ้ 3 ขั้นได้
- ภารกิจสร้างสรรค์ 4 ด้าน × 3 ด่าน (ตารางที่ 2) จับเวลา 5 นาที ทุกคนเขียนพร้อมกัน เพื่อนตรวจ คัดลอกคำตอบเก็บเป็นหลักฐานได้
- ภารกิจร่วม 3 สิ่งมหัศจรรย์ ตลาดแลกคำ ภัยยุ่งเหยิง 16 แบบ การโจมตีเมืองและการซ่อม นิทานเมืองของฉัน และตารางนับแต้ม
- **แหล่งเรียนรู้** (แทนการสแกน AR): แตะไม้ อิฐ หิน หรือแก้วสี เพื่อเปิดบทเรียน 3 ส่วนย่อยพร้อมแบบฝึกสั้น ๆ
- บันทึกเกมไว้ในเครื่องอัตโนมัติ

## แก้ไขเนื้อหา

เนื้อหาร่วมกับชุดพิมพ์อยู่ที่ `../print-and-play/src/data.mjs` ส่วนบล็อกของภารกิจฉบับดิจิทัลอยู่ที่ `src/missions.mjs` ตัวเกมอยู่ที่ `src/template.html` แก้แล้วสร้างไฟล์ใหม่ด้วย

```bash
node digital/build.mjs
```

# หมู่บ้านนักแต่งประโยค (เกมที่ 2)

เกมหน้าเดียว `sentence-village.html` สร้างจากเอกสารออกแบบเนื้อหา "การแต่งประโยค ท 4.1 ป.3/4" เปิดในเบราว์เซอร์ได้ทันที เล่นเป็นกลุ่มหรือคนเดียวก็ได้ บนแท็บเล็ตหรือคอมพิวเตอร์

- **3 ด่านตามลำดับเนื้อหา:** โรงเรียน (การสร้างประโยค) → ตลาด (การใช้ภาษา) → ทุ่งนา (การขยายประโยค) ส่งภารกิจครบแล้วด่านต่อไปจะเปิด
- **ภารกิจ 12 ภารกิจ:** การคิดสร้างสรรค์ 4 ด้านในแต่ละด่าน ตามตารางที่ 2 วัดตามตัวบ่งชี้ 1.1–4.3 ในตารางที่ 3 ใช้กรอบของกิลฟอร์ด (1967) ที่จารุณี ซามาตย์ (2552) สรุปไว้
- **ครบ 7 องค์ประกอบตามแบบประเมินด้านการออกแบบ:**

| องค์ประกอบ | อยู่ตรงไหนในเกม |
|---|---|
| 1. สถานการณ์ปัญหา | การ์ดเปิดด่าน: เรื่องจริงในหมู่บ้าน บทบาทของผู้เรียน คำถามชวนคิด และภารกิจ |
| 2. ศูนย์การเรียนรู้ | ฐานเรียนรู้ 15 ฐาน แผนผังความรู้ และภาพที่แตะส่องดูคำได้ (ใช้แทน AR) |
| 3. เครื่องมือทางปัญญา | ห้องทดลองประโยค (เรียงบล็อกแล้วตรวจ) ตัวแยกคำที่บอกหน้าที่ของคำ และผังจัดความคิด |
| 4. ศูนย์แลกเปลี่ยนเรียนรู้ | กระดานแลกเปลี่ยน: แชร์คำตอบ ให้ดาว และตอบกลับด้วยประโยคชวนคิด |
| 5. ศูนย์ส่งเสริมการคิดสร้างสรรค์ | ภารกิจ 4 ด้าน เคล็ดคิดของแต่ละด้าน และเส้นทาง คิดให้มาก → หลาก → แปลก → ละเอียด |
| 6. ฐานการช่วยเหลือ | ปุ่ม 4 แบบในทุกภารกิจ: ความคิดรวบยอด การคิด กระบวนการ และกลยุทธ์ |
| 7. การโค้ช | ครูฮูกตั้งคำถามกระตุ้นและให้คำแนะนำหลังส่งงาน มีช่องปรึกษาครู |

- **การให้คะแนน:** ระบบให้ดาว 0–3 ตามเกณฑ์อัตโนมัติ ส่วนภารกิจการคิดริเริ่มรอครูให้ดาวความแปลกใหม่ ในโหมดครูปรับคะแนนตามรูบริก ตอบคำปรึกษา และคัดลอกผลทั้งห้องเป็น CSV ได้
- ข้อมูลทุกกลุ่มบันทึกอยู่ในเบราว์เซอร์ของเครื่องที่ใช้เล่น

แก้เนื้อหาได้ที่ `village/src/data.js` ตัววิเคราะห์ภาษาอยู่ที่ `village/src/lang.js` หน้าจออยู่ที่ `village/src/app.js` และ `village/src/shell.html` แก้แล้วสร้างไฟล์ใหม่ด้วย

```bash
node digital/village/build.mjs
```
