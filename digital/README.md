# Block World – อาณาจักรนักสร้างโลกแห่งคำ — ฉบับดิจิทัล

เกมหน้าเดียว `wordland.html` เปิดในเบราว์เซอร์ได้ทันที (แท็บเล็ตหรือคอมพิวเตอร์ 1 เครื่อง ผู้เล่น 2–4 คนผลัดกัน)

- กระดานเป็นภาพ BLOCK WORLD ช่อง 36 ช่องวางบนช่องถนนในภาพ เดินแบบเดียวกับชุดพิมพ์ · เลือกนักสร้างเมืองตัวจิ๋ว 8 แบบเป็นตัวเดิน · แตะอาคาร 7 หลังหรือหอคอยบนภาพเพื่อเปิดองค์ประกอบนั้น
- **ทอยประโยค** ที่ช่องทรัพยากร: ทอยลูกเต๋าใคร + ลูกเต๋าประเภทประโยค + การ์ดเวลา 4 กาล (แบบ Sentence Maker) ต่อประโยคกับกริยาบนช่อง จั่วการ์ดขยายเพิ่มเพื่อรับโบนัส ระบบตรวจทั้งประธาน กริยา คำบอกเวลา ประเภท และตำแหน่งคำช่วย จะ / กำลัง
- ต่อประโยคด้วยการแตะบล็อกคำบนแท่นวาง ระบบตรวจโครงสร้างและประเภทประโยคให้ (บอกเล่า ปฏิเสธ คำถาม คำสั่ง ขอร้อง)
- ภารกิจซ่อมป้าย 36 ภารกิจตรวจคำตอบอัตโนมัติ เมื่อผิด **ครูฮูก** ถามคำถามตามบันไดการโค้ช โดยไม่บอกคำตอบ และเปิดการ์ดคำใบ้ 3 ขั้นได้
- ภารกิจสร้างสรรค์ 4 ด้าน × 3 ด่าน (ตารางที่ 2) จับเวลา 5 นาที ทุกคนเขียนพร้อมกัน เพื่อนตรวจ คัดลอกคำตอบเก็บเป็นหลักฐานได้
- ภารกิจร่วม 3 สิ่งมหัศจรรย์ ตลาดแลกคำ ภัยยุ่งเหยิง 16 แบบ การโจมตีเมืองและการซ่อม นิทานเมืองของฉัน และตารางนับแต้ม
- **แหล่งเรียนรู้** (แทนการสแกน AR): แตะไม้ อิฐ หิน หรือแก้วสี เพื่อเปิดบทเรียน 3 ส่วนย่อยพร้อมแบบฝึกสั้น ๆ
- ครบ 7 องค์ประกอบ: คลังความรู้มีแผนผังความคิดและกระบวนการคิดสร้างสรรค์ 4 ขั้น · 🛟 ฐานช่วยเหลือ 4 ด้าน · 🗣 กระดานแลกเปลี่ยน (ประโยคจากทอยประโยคและภารกิจสร้างสรรค์ขึ้นอัตโนมัติ เพื่อนและครูตอบได้) · 🦉 ปรึกษาครูฮูก (แนะนำขั้นต่อไปตามสถานะผู้เล่น)
- บันทึกเกมไว้ในเครื่องอัตโนมัติ

## แก้ไขเนื้อหา

เนื้อหาร่วมกับชุดพิมพ์อยู่ที่ `../print-and-play/src/data.mjs` ส่วนบล็อกของภารกิจฉบับดิจิทัลอยู่ที่ `src/missions.mjs` ตัวเกมอยู่ที่ `src/template.html` แก้แล้วสร้างไฟล์ใหม่ด้วย

```bash
node digital/build.mjs
```
