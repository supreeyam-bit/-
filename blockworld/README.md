# BLOCK WORLD: อาณาจักรนักสร้างโลกแห่งคำ

เกมเว็บ React + TypeScript สำหรับนักเรียน ป.3 เล่นได้บนคอมพิวเตอร์ แท็บเล็ต และมือถือ ผู้เล่น 2–4 คนผลัดกันเล่นบนเครื่องเดียว (pass-and-play)

## วิธีรัน

```bash
cd blockworld
npm install
npm run dev            # เปิดเครื่องทดสอบ (แท็บเล็ตหรือมือถือในวง Wi-Fi เดียวกันเปิดผ่าน IP ที่แสดงได้)
npm run build          # ได้ไฟล์เว็บใน dist/
npm run build:single   # ได้ไฟล์เดียว dist-single/index.html ส่งต่อหรือเปิดในเครื่องได้เลยโดยไม่ต้องมีเซิร์ฟเวอร์
npm run test:e2e       # ทดสอบการเล่นจริงในเบราว์เซอร์ (ต้อง build:single ก่อน และต้องมี Playwright)
```

## ข้อมูล

| ไฟล์ | เนื้อหา |
|---|---|
| `data/missions_exact_table2.json` | ภารกิจ 12 ใบ (3 โซน × 4 ด้าน) ข้อความ `instruction_exact_from_table_2` ตามต้นฉบับ |
| `data/stations.json` | 7 องค์ประกอบ |
| `data/word_blocks.json` | บล็อกคำและลูกเต๋าเรื่องเล่า |
| `data/tower_exact_alignment.json` | ตัวชี้วัด 4 ด้านสำหรับหอคอย |
| `data/support.json` | คำถามโค้ชและแม่แบบประโยค |

ไฟล์ทั้งหมดสร้างจาก `../print-and-play/src/data.mjs` ด้วย `npm run gen-data` เพราะตอนสร้างยังไม่มีไฟล์ JSON, docx และรูปใน `assets/` ฉบับทางการ ถ้ามีไฟล์ทางการ ให้วางทับใน `data/` ได้เลย โดยต้องใช้โครงสร้างเดียวกัน

## สิ่งที่มีในเกม

- แผนที่ 3 โซนตามลำดับ (การสร้างประโยค → การขยายประโยค → การใช้ภาษา) แต่ละโซนมีเส้นทางวน 10 ช่อง ลูกเต๋า 1 1 2 2 3 3 และตัวเดินย้ายจริง
- องค์ประกอบ 7 อย่าง: สถานการณ์ปัญหา, ศูนย์การเรียนรู้, เครื่องมือทางปัญญา, ศูนย์แลกเปลี่ยนเรียนรู้, ศูนย์ส่งเสริมการคิดสร้างสรรค์ (หอคอยกลาง), ฐานการช่วยเหลือ, การโค้ช
- ภารกิจ 12 ใบ มีตัวจับเวลา 5 นาทีเฉพาะใบที่ตารางระบุเวลา (6 ใบ)
- แท่นเรียงบล็อกคำ (เพิ่ม ลบ ย้าย พิมพ์คำเอง) เก็บฉบับก่อนและหลังแก้ไว้เทียบกัน
- พื้นที่วาดภาพสำหรับภารกิจว่าว ทุ่งนา ลม บันทึกและดาวน์โหลดเป็น PNG ได้
- การ์ดผู้ฟัง (ผู้ใหญ่ เพื่อน น้อง) และปุ่มบันทึกประโยคแยกตามผู้ฟัง
- ผลงานรายบุคคล ได้แก่ หลายประโยค ชนิดและรูปแบบประโยค ส่วนที่ขยาย คำอธิบายเหตุผล และการตรวจตามเกณฑ์ด้วยตนเอง
- ทุกคนต้องผลัดกันเสนอไอเดียก่อน ภารกิจจึงจะผ่านได้
- ฐานการช่วยเหลือ 4 แบบ (Conceptual, Metacognitive, Procedural, Strategic) เปิดได้ตลอดโดยไม่หักคะแนน ครูบันทึกคำแนะนำได้
- โหมดครู (ตั้งรหัสได้) มีปุ่มรับรองคำตอบ ให้ปรับปรุง และบันทึกข้อสังเกต **ไม่มีการตรวจคำตอบด้วยการเทียบข้อความ**
- ผ่านครบ 4 ด้านในโซนแล้วจะเจอคัตซีนบอส ทีมนำผลงานมาเล่าแล้วได้คริสตัล บอสไม่ได้เป็นการสอบเพิ่ม
- หอคอยรวมผลงานทั้งสี่ด้านจากสามโซน พร้อมช่องสะท้อนคิด
- แดชบอร์ดครูแสดงผลงาน 12 ภารกิจ ความคืบหน้า และการใช้ความช่วยเหลือ ส่งออกเป็น JSON/CSV และนำเข้า JSON ได้ ข้อมูลเก็บในเครื่องเท่านั้น
- ส่วน AR ใช้ชื่อว่า "ตัวอย่างการแสดงผล AR" เพราะยังเป็นภาพเคลื่อนไหวจำลอง ไม่ได้ใช้กล้องจริง

เกมนี้เป็นกิจกรรมฝึก ไม่ใช่แบบทดสอบที่ผ่านการตรวจสอบคุณภาพแล้ว

## สิ่งที่ยังไม่เสร็จ

- ยังไม่ได้ใช้ไฟล์ทางการ `missions_exact_table2.json`, `stations.json`, `word_blocks.json`, `tower_exact_alignment.json` และ `กรอบเนื้อหาใหม่.docx` เพราะไม่ได้แนบมา ข้อความภารกิจจึงมาจาก `data.mjs` ในรีโปนี้ ควรเทียบกับ docx อีกครั้ง
- ยังไม่มีรูปจาก `assets/board/` และ `assets/components/` ภาพสถานการณ์และแผนที่ตอนนี้เป็นอีโมจิกับ SVG ที่วาดด้วยโค้ด
- คำอธิบายบทบาทของแต่ละสถานี บทเรียน เนื้อหาฐานการช่วยเหลือ และเรื่องราวบอส เขียนขึ้นใหม่ ควรให้ผู้วิจัยตรวจ
- ข้อมูลเก็บในเครื่องเดียว ยังไม่มีการรวมข้อมูลข้ามเครื่องหรือข้ามห้อง
