# BLOCK WORLD: อาณาจักรนักสร้างโลกแห่งคำ

เกมเว็บต้นแบบนวัตกรรมการเรียนรู้ภาษาไทยสำหรับนักเรียน ป.3 ผู้เล่น 2–4 คนเล่นเป็นทีมบนเครื่องเดียว (ผลัดกันใช้เครื่อง) **ยึดตารางที่ 2 จากไฟล์ “กรอบเนื้อหาใหม่.docx” เป็นข้อกำหนดหลัก**: 3 โซน × 4 ด้านความคิดสร้างสรรค์ = ภารกิจหลัก 12 ภารกิจ ผ่านด่านตรวจของบอส 3 ตัว สะสมคริสตัล 3 ดวง แล้วไปถึงเป้าหมายสุดท้ายที่ศูนย์ส่งเสริมการคิดสร้างสรรค์กลางกระดาน

## วงจรการเล่น

1. หน้าเริ่มเกม: เลือกผู้เล่น 2–4 คน กรอกชื่อ (ค่าตั้งต้นเป็นชื่อสมมติ) เลือกตัวละคร และวิธีรับรองผลงาน
2. ถึงตาใคร กด **ทอยลูกเต๋า** (1–3) ตัวเดินเดินบนแผนที่ isometric ในโซนที่ปลดล็อก แต่ละโซนมี 9 ช่อง ได้แก่ ประตูบอส ช่องภารกิจ ⚪🟩🔺⬢ อย่างละ 1 ช่อง ช่องเรียนรู้ ช่องคำ ช่องอุ่นเครื่อง และช่องโบนัส/พัก/สร้าง
3. ตกช่องภารกิจด้านไหน จะเปิดภารกิจด้านนั้นของโซน หรือเลือกเองจาก **กระดานภารกิจ** ได้เสมอ (ตาละ 1 ภารกิจใหม่) ความสุ่มจึงไม่ปิดโอกาสเรียน
4. ภารกิจมี 4 ขั้น: **สถานการณ์ปัญหา** → **ใบงานของทุกคน** (ทุกคนสร้างคำตอบเองในใบงานของตัวเอง ภารกิจที่ตารางกำหนดเวลามีตัวจับเวลา 5 นาทีรายคน) → **แลกเปลี่ยนเรียนรู้** (เพื่อนทุกคนเสนอความคิดอย่างน้อยคนละ 1 ครั้ง แล้วปรับปรุงคำตอบ) → **ตรวจและรับรอง** โดยครู/โค้ช
5. ครบ 4 ด้านในโซน → **ด่านตรวจของบอส**: ผนึก 4 ดวง (F/FL/O/E) ทุกคนเลือกผลงานที่ดีที่สุดของตนจากภารกิจด้านนั้น ปรับให้ตรงเกณฑ์ของโซน ติ๊กเกณฑ์ และอธิบายเหตุผล → ครูรับรอง → ได้คริสตัล และปลดล็อกโซนถัดไป
6. ครบ 3 คริสตัล → **5. ศูนย์ส่งเสริมการคิดสร้างสรรค์** (เป้าหมายสุดท้าย): จัดนิทรรศการ 4 ชั้น ทุกคนเลือกผลงานด้านนั้นจาก 3 โซนพร้อมเหตุผล ครบ 4 ชั้นหอคอยเปล่งแสงและจบเกม หอคอยไม่เพิ่มภารกิจใหม่นอกตารางที่ 2

คีย์ลัด: `R` ทอยลูกเต๋า · `E` จบตา · `M` กระดานภารกิจ · `H` ฐานการช่วยเหลือ · `Esc` ปิดหน้าต่าง

## กลไกเสริมความสนุก (ไม่เปลี่ยนเป้าหมายหรือขอบเขตภารกิจ)

- **Sentence Builder**: เรียงบล็อกคำ ผู้ทำ → การกระทำ → ผู้รับการกระทำ → คำขยาย ด้วยการแตะ หรือลาก-วางบนคอมพิวเตอร์ ผู้เรียนเลือกหน้าที่ของคำเอง
- **Story Cubes**: ในภารกิจคิดริเริ่ม ลูกเต๋า 3 ลูกตั้งหน้า ลม · ว่าว · ทุ่งนา ไว้ตามตารางที่ 2 ส่วนลูกอื่นทอยเพื่อจุดประกายความคิด (การทอยอิสระทุกลูกระบุว่าใช้นอกเวลาเก็บข้อมูล)
- **Dixit (เกมทายภาพฝัน)**: ไม่บังคับ ผู้เล่าเลือกการ์ดลับแล้วแต่งประโยคบรรยาย เพื่อนทาย
- **การ์ดผู้ฟัง**: แม่ ผู้ใหญ่ เพื่อน น้อง คุณครู พร้อมคำแนะนำการเลือกคำเรียกและคำลงท้าย ใช้ในภารกิจโซนการใช้ภาษา
- **กระดานวาดภาพ**: วาดภาพประกอบในภารกิจคิดริเริ่ม ภาพจากโซน 1 ใช้ต่อในโซน 2 และนำไปชี้ประกอบในโซน 3
- **การ์ดฝึกอุ่นเครื่อง F01/FL01/O01/E01** (ช่องอุ่นเครื่อง): เป็นกิจกรรมฝึก ใช้ภาพต่างจากแบบวัด ไม่นับเป็นภารกิจหลัก

## เจ็ดองค์ประกอบของสิ่งแวดล้อมทางการเรียนรู้ (สถานีบนกระดาน)

1. สถานการณ์ปัญหา · 2. ศูนย์การเรียนรู้ (บทเรียน 15 เรื่อง + AR จำลองของ 4 สถานการณ์) · 3. เครื่องมือทางปัญญา · 4. ศูนย์แลกเปลี่ยนเรียนรู้ · 5. ศูนย์ส่งเสริมการคิดสร้างสรรค์ (หอคอยกลาง) · 6. ฐานการช่วยเหลือ (4 แบบ ไม่หักคะแนน) · 7. การโค้ช (คำถามปลายเปิด + แผงครู)

## การบันทึกผลงานและการแยกคะแนน

- เก็บผลงาน **รายบุคคล** ทุกช่องคำตอบ ทั้งก่อนแก้และหลังแก้ รวมถึงภาพวาด ตัวจับเวลา ความเห็นของเพื่อน และความช่วยเหลือที่ใช้
- แดชบอร์ดครูมีตาราง **ตัวบ่งชี้ 1.1–4.3 รายคน** ที่นับจากภารกิจหลักที่ผ่านการรับรอง พร้อมช่องบันทึกพฤติกรรมตามตัวบ่งชี้
- **คะแนนกิจกรรมในเกม** (ครูให้ 0–4 ต่อคนต่อภารกิจ) แยกจาก **คะแนนเครื่องมือวิจัย** ซึ่งวัดนอกเกมด้วยแบบวัดฉบับจริง ระบบไม่คำนวณ ไม่เก็บ และไม่รวมคะแนนวิจัย แดชบอร์ดแสดงข้อความ “ข้อมูลกิจกรรมฝึก ไม่ใช่คะแนนเครื่องมือวิจัยที่ผ่านการตรวจสอบ”
- ส่งออก JSON และ CSV ได้ (CSV แยกแถวรายคน มี UTF-8 BOM ให้ Excel อ่านภาษาไทยถูก) ข้อมูลอยู่ในเครื่องเท่านั้น (localStorage)

## พัฒนาต่อ

```bash
cd blockworld
npm install
npm run dev        # เปิดเซิร์ฟเวอร์พัฒนา
npm test           # ทดสอบกติกาและข้อมูลตารางที่ 2 (vitest)
npm run build      # ตรวจชนิดข้อมูล + สร้าง dist/ และ blockworld.html ใหม่
npm run smoke      # เล่นเกมจริงในเบราว์เซอร์ตั้งแต่ต้นจนจบ (ต้องมี Playwright + Chromium)
```

## ผลการทดสอบ (รันจริง)

- `npm test`: 19 ข้อผ่าน ครอบคลุมโครงสร้าง 3 โซน × 4 ด้าน, สถานการณ์เดิมของแต่ละด้าน, คำสั่งและตัวบ่งชี้ตรงกับตารางที่ 2 ทุกช่อง, เงื่อนไขเฉพาะ (เวลา 5 นาที, ประโยค 2/3 ส่วน, 4 ชนิด, ≥ 3 รูปแบบ, ผู้ฟัง 3 กลุ่ม, คำขยาย 4 ด้าน, เหตุผล, ภาพประกอบ), ชื่อ 7 องค์ประกอบ, การปลดล็อกบอส/โซน/หอคอย และหลักฐานรายบุคคลตามตัวบ่งชี้
- `npm run smoke`: เล่นจริง 2 ผู้เล่นครบทั้ง 12 ภารกิจ (ทุกคนกรอกใบงานของตัวเอง เริ่มเวลา วาดภาพ แลกเปลี่ยน แก้ไข ครูรับรองและให้คะแนนในเกม) ผ่านด่านตรวจของบอส 3 ตัว จัดนิทรรศการ 4 ชั้นจนจบเกม ตรวจตารางตัวบ่งชี้ ส่งออก CSV/JSON และรีเฟรชหน้าแล้วความคืบหน้ายังอยู่ ผ่าน 62 จุดตรวจ ไม่มี error ในคอนโซล (รวมการทอยหลายตาที่ตกช่องภารกิจ)

## สิ่งที่ควรรู้

- ไม่ได้รับไฟล์ “กรอบเนื้อหาใหม่.docx” ในงานนี้โดยตรง ตารางที่ 2 คัดลอกมาจากข้อมูลชุดพิมพ์ในรีโปนี้ (`print-and-play/src/data.mjs`) ซึ่งถอดจากไฟล์ดังกล่าวไว้ก่อนแล้ว หากต้นฉบับมีถ้อยคำต่างจากนี้ ให้แก้ที่ข้อมูลชุดพิมพ์ แล้ว unit test จะชี้จุดที่ต้องแก้ในเกม
- ไม่ได้รับภาพกระดานต้นแบบ แผนที่ isometric จึงวาดด้วย SVG ตามคำบรรยาย (เกาะลอยฟ้าแบบ voxel น้ำตก สะพานไม้ หอคอยกลาง)
- AR เป็นตัวอย่างจำลอง มีป้าย “ตัวอย่างการแสดงผล AR” ไม่ได้สแกน AR จริง
- ระบบตรวจเบื้องต้นดูแค่กลุ่มคำและแสดงเป็นคำแนะนำ การให้ผ่านขึ้นกับครู/โค้ช
- ภารกิจที่จับเวลา 5 นาที: หมดเวลาแล้วเพิ่มข้อใหม่ไม่ได้ แต่ยังแก้คำตอบเดิมได้ (ระบบเก็บก่อนแก้/หลังแก้) ครูให้เวลาใหม่ได้ในโหมดครู
- เกมเปลี่ยนรูปแบบบันทึกเป็นรุ่นใหม่ เกมที่เล่นค้างไว้จากรุ่นก่อนจะไม่ถูกโหลด
- เรื่องเล่าของโซน บอส และกลไกเสริมเป็นข้อเสนอการออกแบบ ควรให้ครูผู้เชี่ยวชาญตรวจทานภาษาก่อนใช้จริง
