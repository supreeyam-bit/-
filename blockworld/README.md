# BLOCK WORLD: อาณาจักรนักสร้างโลกแห่งคำ

เกมเว็บ React + TypeScript สำหรับนักเรียน ป.3 ผู้เล่น 2–4 คนผลัดกันเล่นบนเครื่องเดียว (pass-and-play)
เป็น **กิจกรรมฝึก** ไม่ใช่แบบทดสอบที่ผ่านการตรวจสอบคุณภาพ

## วิธีรัน

```bash
cd blockworld
npm install
npm run dev          # เปิด http://localhost:5173
```

| คำสั่ง | ผล |
|---|---|
| `npm run build` | ตรวจชนิดข้อมูล + สร้างเว็บใน `dist/` (เปิดผ่านเว็บเซิร์ฟเวอร์ หรือ `npm run preview`) |
| `npm run build:single` | ได้ไฟล์ `dist-single/index.html` ไฟล์เดียว ดับเบิลคลิกเปิดได้เลยโดยไม่ต้องมีเซิร์ฟเวอร์หรืออินเทอร์เน็ต |
| `npm run test:e2e` | ทดสอบการเล่นจริงในเบราว์เซอร์ (ต้อง `npm run build` ก่อน) ภาพหน้าจออยู่ที่ `e2e-shots/` |

## เนื้อหาและแหล่งข้อมูล

| ไฟล์ | เนื้อหา |
|---|---|
| `data/missions_exact_table2.json` | ภารกิจ 12 ใบ (3 โซน × 4 ด้าน Guilford) ช่อง `instruction_exact_from_table_2` แสดงบนการ์ดภารกิจทุกคำ |
| `data/stations.json` | 7 องค์ประกอบ (ชื่อไทยตามต้นฉบับ) เป็นสถานีบนกระดาน ไม่ใช่ 7 โซน |
| `data/word_blocks.json` | บล็อกคำในเครื่องมือเรียงประโยค |
| `data/tower_exact_alignment.json` | การจัดหอคอยกลางให้ตรงตัวชี้วัดของแต่ละด้านในแต่ละโซน |

> **ข้อควรทราบ:** ไฟล์ต้นฉบับ `.docx` และไฟล์ JSON ของผู้วิจัยไม่ได้แนบมาในงานนี้ ข้อความคำสั่งทั้ง 12 ข้อจึงดึงจาก
> ตารางที่ 2 ที่ถอดไว้แล้วในโครงการ (`print-and-play/src/data.mjs`) ผ่าน `scripts/extract-data.mjs`
> ควรตรวจทานกับต้นฉบับอีกครั้ง หากมีไฟล์ JSON ของผู้วิจัย **วางทับไฟล์ใน `data/` ได้ทันที** (ใช้ชื่อช่องเดียวกัน)
> `stations.json` และ `tower_exact_alignment.json` สร้างขึ้นใหม่จากชื่อใน prompt และตัวชี้วัด คำถามสะท้อนคิดในหอคอยเป็นคำถามปลายเปิด ไม่ใช่แบบวัด

### ภาพต้นแบบ (ไม่บังคับ)
โฟลเดอร์ `assets/board/` และ `assets/components/` ไม่ได้แนบมา เกมจึงวาดกระดานและภาพสถานการณ์ด้วย SVG/CSS เอง
เมื่อมีไฟล์ ให้วางไว้ที่ `public/assets/...` ตามชื่อด้านล่าง เกมจะแสดงภาพต้นแบบซ้อนกับ UI ที่เล่นได้อัตโนมัติ (ข้อความไทยยังแสดงจาก JSON เป็น HTML ทับอยู่)

`board/board.png` · `board/zone-1.png` … `zone-3.png` · `components/situation-1.png` … `situation-4.png` (คล่อง ยืดหยุ่น ริเริ่ม ละเอียดลออ) · `components/tower.png` · `components/boss-1.png` … `boss-3.png`

## วิธีเล่น (สรุป)
1. เลือกผู้เล่น 2–4 คน ตั้งชื่อสมมติ (ตั้งรหัสโหมดครูได้)
2. ทอยลูกเต๋า (หน้า 1,1,2,2,3,3) ตัวเดินเดินบนวง 12 ช่องของโซนปัจจุบัน ช่องที่หยุดจะเปิดอัตโนมัติ ทุกสถานีกดเปิดเองได้ตลอด
3. ช่องสถานการณ์ปัญหา = การ์ดภารกิจ ผู้เล่นแต่ละคนทำชิ้นงานของตนเอง → ผลัดกันเสนอไอเดียในศูนย์แลกเปลี่ยนเรียนรู้ → ส่งให้ครู/โค้ชตรวจ
4. ครูเปิด **โหมดครู** แล้วกด รับรองคำตอบ / ให้ปรับปรุง / บันทึกข้อสังเกต ภารกิจสำเร็จเมื่อทุกคนเสนอไอเดียและครูรับรองครบ (ไม่มีการตรวจด้วยการเทียบคำตอบอัตโนมัติ)
5. ครบ 4 ด้านในโซน → เผชิญบอสที่ประตู (ทุกคนเลือกผลงานที่รับรองแล้วอ่านให้ทีมฟัง) → ได้คริสตัล → โซนถัดไป
6. หอคอยกลาง (ศูนย์ส่งเสริมการคิดสร้างสรรค์) รวมผลงานครบสี่ด้านจากสามโซน และพื้นที่สะท้อนคิด

## ส่วนประกอบในโค้ด (`src/`)
| ไฟล์ | หน้าที่ |
|---|---|
| `components/Board.tsx` | แผนที่สามโซน ช่อง/สถานีที่กดได้ หอคอยกลาง ตัวเดิน 4 สี ลูกเต๋า |
| `components/MissionPanel.tsx`, `WorkEditor.tsx` | การ์ดภารกิจ ข้อความตามตาราง ตัวจับเวลา และชิ้นงานรายบุคคล (หลายประโยค ช่องชนิดประโยค การ์ดผู้ฟัง คำขยาย ฉบับก่อน/หลัง เหตุผล ภาพวาด) |
| `components/SentenceBuilder.tsx` | เรียงบล็อกคำ + พิมพ์คำอิสระ เพิ่ม ลบ ย้าย (ปุ่มหรือลาก) เทียบฉบับก่อน/หลัง |
| `components/DrawingPad.tsx` | พื้นที่วาดภาพ (ว่าว ทุ่งนา ลม) บันทึกเป็น PNG ในชิ้นงาน ภารกิจถัดไปวาดต่อจากภาพเดิม |
| `components/Timer.tsx` | นับถอยหลัง 5 นาที เฉพาะ 6 ภารกิจที่ตารางกำหนดเวลา |
| `components/Exchange.tsx`, `Help.tsx`, `Coach.tsx` | ศูนย์แลกเปลี่ยนเรียนรู้ · ฐานการช่วยเหลือ 4 แบบ (ไม่หักคะแนน) · การโค้ช |
| `components/Stations.tsx` | สถานการณ์ปัญหา ศูนย์การเรียนรู้ เครื่องมือทางปัญญา หอคอย บอส/คริสตัล คลังของทีม รายการภารกิจ |
| `components/Dashboard.tsx` | แดชบอร์ดครู: ความคืบหน้า 12 ภารกิจ ผลงาน ความช่วยเหลือ การโค้ช ส่งออก JSON/CSV นำเข้า JSON |
| `store.ts` | สถานะเกม เก็บใน localStorage ของเครื่องโดยค่าเริ่มต้น |

## สิ่งที่ยังไม่เสร็จ / ข้อจำกัด
- ข้อความภารกิจยังไม่ได้เทียบกับไฟล์ `.docx` ต้นฉบับโดยตรง (ไม่ได้รับไฟล์)
- ยังไม่มีภาพต้นแบบจริง ใช้ภาพวาดด้วยโค้ดและอีโมจิแทน
- AR เป็น **ตัวอย่างการแสดงผล AR** (แอนิเมชันจำลอง) ยังไม่ใช่ WebAR ที่ใช้กล้อง
- ไม่มีการบันทึกเสียง การ "เล่าให้ผู้ฟัง" เก็บเป็นข้อความต่อการ์ดผู้ฟัง ส่วนการพูดจริงเกิดในห้องเรียน
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว ไม่ซิงก์ข้ามเครื่อง ภาพวาดจำนวนมากอาจทำให้พื้นที่ localStorage (~5 MB) เต็ม — ระบบจะเตือนให้ส่งออก JSON
- ผ่านการทดสอบอัตโนมัติบน Chromium เดสก์ท็อปและจอกว้าง 390px ยังไม่ได้ทดสอบบนแท็บเล็ตจริงหรือ Safari
