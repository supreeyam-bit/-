# หมู่บ้านนักแต่งประโยค — บอร์ดเกม (Print & Play)

บอร์ดเกมการเรียนรู้ภาษาไทย ป.3 เรื่อง การแต่งประโยค (ท 4.1 ป.3/4) สำหรับผู้เล่น 2–4 คนหรือ 2–4 ทีม เล่นแบบร่วมมือ 4 คาบ คาบละ 1 ด่าน ด่านคือสถานการณ์ปัญหา 4 เรื่องตามการคิดสร้างสรรค์ 4 ด้าน (คล่อง ยืดหยุ่น ริเริ่ม ละเอียดลออ) และทุกด่านครอบคลุมเนื้อหา 3 ด้าน (การสร้างประโยค การใช้ภาษา การขยายประโยค) เป็นฉบับกระดานของเกมดิจิทัล `digital/sentence-village.html` และใช้เนื้อหาชุดเดียวกัน

## องค์ประกอบ 7 ด้าน

| องค์ประกอบ | ชิ้นส่วนในบอร์ดเกม |
| --- | --- |
| 1. สถานการณ์ปัญหา | 4 ด่านตามการคิดสร้างสรรค์ 4 ด้าน แต่ละด่านมีการ์ดเปิดด่าน การ์ดสถานการณ์ครบเนื้อหา 3 ด้าน และแผงปัญหาบนกระดาน |
| 2. ศูนย์การเรียนรู้ | ช่องฐานเรียนรู้แยกสีตามเนื้อหา 3 ด้าน การ์ดฐานเรียนรู้ 15 ฐาน แผนผังความรู้ ภาพบนการ์ดพร้อมมาร์กเกอร์ AR |
| 3. เครื่องมือทางปัญญา | บล็อกคำ 5 สี แท่นเรียงประโยคพร้อมเกณฑ์ตรวจ 4 ข้อ ผังจัดความคิด |
| 4. ศูนย์แลกเปลี่ยนเรียนรู้ | เล่นแบบร่วมมือ วงแลกเปลี่ยนหลังภารกิจ ตลาดแลกคำ กระดานแลกเปลี่ยน |
| 5. ศูนย์ส่งเสริมการคิดสร้างสรรค์ | การ์ดภารกิจ 12 ใบ (4 ด่านการคิด × 3 ด้านเนื้อหา) ด่านเรียงตามกระบวนการ คิดให้มาก → หลาก → แปลก → ละเอียด |
| 6. ฐานการช่วยเหลือ | โทเคนและการ์ดฐานช่วยเหลือ 4 แบบ: ความคิดรวบยอด การคิด กระบวนการ กลยุทธ์ |
| 7. การโค้ช | การ์ดครูฮูกที่ถามชวนคิดโดยไม่บอกคำตอบ และบทบาทครูในคู่มือ |

มาร์กเกอร์ AR บนการ์ดเป็นลายตัวแทน ใช้ลายเดียวกับชุดพิมพ์ `print-and-play/` รอลงทะเบียนในแอป AR

## แก้ไขเนื้อหาและสร้างไฟล์ใหม่

เนื้อหาหลัก (สถานการณ์ปัญหา ฐานเรียนรู้ ภารกิจ ตัวบ่งชี้) อ่านจาก `digital/village/src/data.js` ซึ่งเป็นไฟล์เดียวกับเกมดิจิทัล ส่วนข้อมูลเฉพาะบอร์ดเกม (ช่องบนกระดาน การ์ดสถานการณ์ การ์ดครูฮูก บล็อกคำ) อยู่ใน `src/data.mjs` แก้แล้วสร้าง PDF ใหม่ด้วย

```bash
node village-board/src/build.mjs          # ทุกไฟล์
node village-board/src/build.mjs 04-      # เฉพาะไฟล์ที่ชื่อมี "04-"
```

ต้องมี Playwright (Chromium) และ `pypdf` เช่นเดียวกับ `print-and-play/` ฟอนต์ Mitr และ Sarabun ใช้จาก `print-and-play/fonts/`
